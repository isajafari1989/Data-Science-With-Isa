# Smart Teleprompter

A free teleprompter by **Data Science with Isa**. It is one web page: nothing to install, and no account.

**Open it:** [https://isajafari1989.github.io/Data-Science-With-Isa/teleprompter/](https://isajafari1989.github.io/Data-Science-With-Isa/teleprompter/)

On a phone, use that https link. Phone browsers only allow the camera on a secure page.

## Features

- Paste any script.
- Auto-save in the browser, so the script is still there next time you open the page on this device.
- Adjustable speed, text size, and reading line.
- Mirror, for a glass teleprompter.
- Countdown before the scroll starts.
- Voice-follow that scrolls as you speak (Chrome or Edge, and it needs internet).
- Camera mode with in-page recording. The text is not recorded — only the camera and microphone.

## Keyboard shortcuts

| Key | What it does |
| --- | --- |
| Space | Play or pause |
| Arrow keys | Change the speed |
| + / − | Change the text size |
| V | Voice-follow on or off |
| R | Record or stop |
| F | Full screen |
| Esc | Back to editing |

## Privacy

Everything runs in your browser. Scripts are stored only in your browser. Nothing is uploaded, except that Chrome's built-in speech recognition uses the browser vendor's speech service.
